Images and cursors used by the Blocks editor, copied from `node_modules/blockly/media/`
(Blockly 13.4, Apache-2.0, https://github.com/RaspberryPiFoundation/blockly). Served with
the site so Blockly doesn't fetch them from a CDN. Sounds are left out (they're turned off).
If you upgrade Blockly, copy these files again.
